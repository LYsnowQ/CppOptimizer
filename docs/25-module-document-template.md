## 13. Definition of Done

### 正式工程完成

- 代码、文档、构建配置和测试同步；
- 权限不足、不支持、超时、取消和部分失败已处理；
- 资源、线程和恢复路径经过审查；
- Experimental 功能默认关闭；
- 日志、性能预算、长稳和发布默认值满足要求。

### 学习完成

- 学习者独立完成至少一个函数；
- 学习者设计至少一个测试；
- 学习者完成至少一个安全变体；
- 能解释 API 选型、失败值、错误域、所有权和关键失败路径；
- 能说明绿/黄/红边界；
- 关键小函数可在不看答案时重写。

## 14. 学习复盘

1. 最容易误解的 API 是什么？
2. 为什么选当前 API，而不是替代方案？
3. 哪些返回值代表失败？错误属于哪个域？
4. 每种资源由谁释放，使用哪个函数？
5. 如果第二步失败，第一步的资源如何清理？
6. 权限不足、不支持或目标退出时如何降级？
7. 哪些参数可以安全变化？
8. 哪些不变量不可破坏？
9. 哪些行为仍属于红色区域？
10. Windows 更新后如何安全失效？
